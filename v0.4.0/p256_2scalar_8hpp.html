Detailed Description

Scalars of P-256: integers modulo the group order n.

Overview

scalar holds an integer modulo P-256's group order n in Montgomery form: private keys, nonces and the ECDSA arithmetic of p256/ecdsa.hpp.

Relationships

detail/mont256.hpp; p256/ecdsa.hpp. Group: P-256.

Implementations and variants

One: Montgomery multiplication (CIOS, four 64-bit limbs) with a masked final subtraction; Fermat's inverse.

Guarantees and contracts

Constant time throughout: a private key or a nonce never decides a branch or an index; from_bytes declassifies only whether the bytes were below n. constexpr, noexcept, no allocation.

Errors

from_bytes returns std::nullopt for a value at or above n.

Examples
using snicholls::crypto::p256::scalar;
const auto n = scalar::order_bytes();
const bool inverse_ok = scalar::from_u64(5) * scalar::from_u64(5).inverse() == scalar::from_u64(1);
const scalar reduced = scalar::from_bytes_reduced(hex<32>("ffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffff"));
const bool n_refused = !scalar::from_bytes(n).has_value(); // a scalar is below n

Tests and demos

tests/p256/scalar_test.cpp: identities at compile time, n - 1, reduction of values at and above n. demos/p256/scalar_demo.cpp.

Dependencies

<array>, <cstdint>, <optional>, <span>; core's result.hpp and SHA-256; detail/mont256.hpp.

Known issues and gotchas

A scalar of zero is a valid element but not a valid private key: p256/ecdsa.hpp's private_key refuses it.

Status

Experimental (0.3).

Detailed Description

template<std::size_t N>
class snicholls::crypto::secret_bytes< N >

N bytes of key material: inline, wiped on destruction, copied only on request.

Template Parameters
NThe number of bytes.
Overview

See the file description. A move wipes the source; clone() makes an explicit copy.

Guarantees and contracts

noexcept and constexpr throughout. The layout is exactly std::array<std::uint8_t, N>.

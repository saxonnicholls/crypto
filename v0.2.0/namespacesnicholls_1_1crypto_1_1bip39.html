enum class snicholls::crypto::bip39::passphrase_form : unsigned char
strong

How a passphrase is given to to_seed.

Enumerator
ascii 

ASCII only (NFKD leaves it unchanged); anything else is refused.

nfkd 

Any UTF-8 the caller has already normalised to NFKD; hashed byte for byte.

◆ high_s

enum class snicholls::crypto::secp256k1::high_s : unsigned char
strong

Whether verification accepts an s above n / 2.

Enumerator
accept 

Textbook ECDSA (and Wycheproof's expectations): both s and n - s verify.

reject 

Bitcoin (BIP-62 / BIP-146) and Ethereum transactions (EIP-2): only s <= n / 2.

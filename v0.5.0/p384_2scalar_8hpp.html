Detailed Description

Scalars of P-384: integers modulo the group order n.

Overview

scalar holds an integer modulo P-384's group order n in Montgomery form: private keys and the ECDSA arithmetic of p384/ecdsa.hpp.

Relationships

detail/mont.hpp, detail/mont_residue.hpp (shared with P-256); p384/ecdsa.hpp. Group: P-384.

Implementations and variants

One: Montgomery multiplication (CIOS, six 64-bit limbs) with a masked final subtraction; Fermat's inverse.

Guarantees and contracts

Constant time throughout: a private key never decides a branch or an index; from_bytes declassifies only whether the bytes were below n. constexpr, noexcept, no allocation.

Errors

from_bytes returns std::nullopt for a value at or above n.

Examples
using snicholls::crypto::p384::scalar;
const auto n = scalar::order_bytes();
const bool inverse_ok = scalar::from_u64(5) * scalar::from_u64(5).inverse() == scalar::from_u64(1);
const scalar reduced = scalar::from_bytes_reduced(
hex<48>("ffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffff"));
const bool n_refused = !scalar::from_bytes(n).has_value(); // a scalar is below n

Dependencies

<array>, <cstdint>; detail/mont.hpp, detail/mont_residue.hpp.

Known issues and gotchas

A scalar of zero is a valid element but not a valid private key: p384/ecdsa.hpp's private_key refuses it. A 48-byte hash is reduced modulo n with from_bytes_reduced (SHA-384's length is the order's).

Status

Experimental (0.5).

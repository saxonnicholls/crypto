A key from its components, big-endian with no leading zero byte (a JWK's n, e, p, q, dp, dq and qi, decoded). Constant time in p, q, dp, dq and qinv; n and e are public.

Parameters
nThe modulus.
eThe public exponent.
pThe first prime.
qThe second prime.
dpd mod (p - 1).
dqd mod (q - 1).
qinvq^-1 mod p.
Returns
The key; errc::non_canonical for a leading zero byte; errc::invalid_private_key for a public part public_key::from_components refuses, a prime over 2048 bits, or a key that fails its checks.

◆ sign_encoded()

result< void, errc > snicholls::crypto::rsa::private_key::sign_encoded ( std::span< const std::uint8_t > em,
std::span< std::uint8_t > out ) const
inlinenodiscardconstexprnoexcept

RSASP1 with its check (RFC 8017 5.2.1): out = em^d mod n, verified with the public key before it is returned. For the signature schemes of this header and for tests; em is an encoded message, never raw data. Constant time in the key.

Parameters
emThe encoded message, exactly modulus_bytes() long and below the modulus (public).
outThe signature, exactly modulus_bytes() long; zeroed on any error.
Returns
Success; errc::invalid_length for another length; errc::signing_fault when em is not below the modulus or the result did not verify.

Detailed Description

curve25519::scalar: integers modulo L = 2^252 + 27742317777372353535851937790883648493, the order of edwards25519's prime subgroup; constant-time and constexpr.

Overview

Ed25519's secret scalar, its nonce r, the challenge k and the signature's S. Stored as 32 little-endian bytes, always below L. reduce takes a 64-byte hash to a scalar; mul_add computes S = k a + r; is_canonical is the S < L check that keeps signatures from being malleable.

Relationships
  • curve25519/edwards.hpp: multiplies points by these.
  • curve25519/ed25519.hpp: the user.
  • Group: Curve25519.
Implementations and variants

One: the reduction works on 64 signed 64-bit digits of 8 bits each, folding the top digits down by L's low part (the method TweetNaCl popularised), then a final carry pass; every loop has a fixed trip count.

Guarantees and contracts
  • Value type, trivially copyable, no allocation; every member constexpr and noexcept.
  • reduce, mul_add, from_bytes_reduced: constant time in their arguments.
  • is_canonical / from_canonical: constant time; from_canonical returns std::nullopt for S >= L (that branch is on a public signature).
  • A scalar holding a secret is wiped by its owner (ed25519::key_pair does); the type stays trivially copyable.
Errors

None: a non-canonical encoding is std::nullopt.

Examples
using snicholls::crypto::curve25519::scalar;
std::array<std::uint8_t, 64> digest{};
digest.fill(0xff); // a 64-byte hash, as SHA-512 gives
const scalar h = scalar::reduce(digest); // reduced modulo L
const scalar s = scalar::mul_add(scalar::from_u64(6), scalar::from_u64(7), scalar::from_u64(8)); // 6 * 7 + 8
const auto order = snicholls::crypto::test::hex<32>("edd3f55c1a631258d69cf7a2def9de1400000000000000000000000000000010");
const bool l_is_canonical = scalar::is_canonical(order); // S = L would be malleable: refused

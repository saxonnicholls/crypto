 An integer modulo p, kept in Montgomery form, fully reduced: from_u64, from_bytes (strict: refused at or above p), from_bytes_ct, to_bytes, +, -, *, square, inverse (Fermat), sqrt_ct (p = 3 mod 4), is_odd, is_zero_mask, select, ==. The class is detail::mont_residue<4, ...>, shared with P-384.

Detailed Description

The field of P-256: integers modulo p = 2^256 - 2^224 + 2^192 + 2^96 - 1.

Overview

field_element holds an integer modulo P-256's prime in Montgomery form; addition, subtraction, multiplication, Fermat's inverse and the square root (p = 3 mod 4). Used by p256/point.hpp.

Relationships

detail/mont.hpp and detail/mont_residue.hpp (the arithmetic and the class, shared with p256/scalar.hpp and P-384); p256/point.hpp. Group: P-256.

Implementations and variants

One: Montgomery multiplication (CIOS, four 64-bit limbs) with a masked final subtraction.

Guarantees and contracts

Constant time throughout, for secret or public values alike (no branch or index on a value); from_bytes declassifies only whether the bytes were canonical. constexpr, noexcept, no allocation.

Errors

from_bytes returns std::nullopt for a value at or above p.

Examples
using snicholls::crypto::p256::field_element;
const field_element seven = field_element::from_u64(7);
const bool inverse_ok = seven * seven.inverse() == field_element::from_u64(1);
std::uint64_t is_square = 0;
const field_element root = field_element::from_u64(9).sqrt_ct(is_square); // 3 or p - 3
const auto p = field_element::from_bytes(hex<32>("ffffffff00000001000000000000000000000000ffffffffffffffffffffffff")); // std::nullopt
Performance

One multiplication: 16 64-bit products and a reduction of the same size. See BENCHMARKS.md (p256/ecdsa).

Tests and demos

tests/p256/field_test.cpp: identities at compile time (inverse, square root, distributivity), boundary values. demos/p256/field_demo.cpp.

Dependencies

<array>, <cstdint>, <optional>, <span>; core's result.hpp and SHA-256; detail/mont256.hpp.

Known issues and gotchas

Values are in Montgomery form: compare them with == only against other field_elements, and read them with to_bytes or canonical.

Status

Experimental (0.3).

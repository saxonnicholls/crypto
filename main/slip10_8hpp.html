Detailed Description

SLIP-10 key derivation for Ed25519: the master key from a seed and hardened child derivation.

Overview

Ed25519 keys cannot be added like secp256k1 scalars, so SLIP-10 derives them with HMAC-SHA512 keyed by "ed25519 seed" for the master and by the chain code for each child, and defines only hardened children: every index must be at least 2^31. A non-hardened index is refused (errc::hardened_required), never silently hardened, so a path written for another curve cannot quietly derive a different key. The node's 32-byte key is an Ed25519 seed (RFC 8032's private key): key_pair() makes the signing key, public_key() its public half. Solana, Stellar and others derive their keys this way (m/44'/501'/0'/0' for Solana).

Relationships
  • hd/bip32.hpp: the secp256k1 counterpart; hd/path.hpp: the paths; curve25519/ed25519.hpp: the keys.
  • Group: Wallets.
Implementations and variants

One: SLIP-10 for ed25519. SLIP-10's secp256k1 derivation is BIP-32's, which hd/bip32.hpp implements (its vectors are tested there); NIST P-256 and curve25519 (X25519) derivation are not provided.

Guarantees and contracts
  • Constant time in the seed, the keys and the chain codes (HMAC-SHA512, then copies); the public key is the constant-time Ed25519 base multiplication. Keys and chain codes live in secret_bytes and are wiped; slip10_ed25519_key is move-only, clone() copies.
  • constexpr, noexcept, no allocation.
Errors

errc::invalid_seed for a seed outside 16 to 64 bytes; errc::hardened_required for any index below 2^31.

Examples
const auto seed = snicholls::crypto::test::hex<16>("000102030405060708090a0b0c0d0e0f"); // SLIP-10 vector 1
const auto master = slip10_ed25519_key::from_seed(seed).unwrap();
const auto node = master.derive(derivation_path::parse("m/0'/1'/2'").unwrap()); // hardened only
const auto signer = node->key_pair(); // an Ed25519 key pair
const auto soft = master.derive(derivation_path::parse("m/0'/1").unwrap()); // refused, never hardened
Performance

One HMAC-SHA512 per step; public_key() and fingerprint() cost one Ed25519 base multiplication each. See benchmarks/hd/bip32_benchmark.cpp.

Tests and demos

tests/hd/slip10_test.cpp: SLIP-10's ed25519 test vectors 1 and 2 (fingerprints, chain codes, private and public keys at every depth) and the refusal of non-hardened indices. demos/hd/slip10_demo.cpp.

Dependencies

<array>, <cstdint>, <span>; core's result.hpp; the library's HMAC-SHA512, HASH160 and Ed25519.

Known issues and gotchas

SLIP-10 writes an Ed25519 public key as 33 bytes, a 00 byte before the 32-byte key, and fingerprints that form; public_key() returns the 32-byte key, fingerprint() hashes the 33-byte form as SLIP-10 does.

Status

Experimental (0.1).

Detailed Description

Points of P-384 (y^2 = x^3 - 3x + b): complete projective addition and scalar multiplication.

Overview

point is a point of P-384 in homogeneous projective coordinates (X : Y : Z), the identity being (0 : 1 : 0). Addition uses complete formulas, correct for every pair of inputs including the identity and doubling, so no input decides a branch. mul is the constant-time multiplication used with secrets (keys, ECDH); mul_add_public computes a G + b Q in variable time for verification. affine_point is the decoded form, with SEC1 encoding (49 or 97 bytes) and the curve equation.

Relationships
  • detail/weierstrass_a3.hpp: the one implementation, shared with P-256's points; p384/field.hpp, p384/scalar.hpp; p384/ecdsa.hpp and p384/ecdh.hpp use it.
  • Group: P-384.
Implementations and variants

One: Renes, Costello and Batina's complete addition for a = -3 (Eurocrypt 2016, Algorithm 4), doubling as an addition of a point to itself, and a 4-bit fixed window whose table entry is read by a masked scan of all 16.

Guarantees and contracts
  • operator+, dbl, mul, mul_base, select, to_affine_ct: constant time (fixed operation sequences; the window's table is scanned whole); the scalar of mul may be secret.
  • mul_add_public, to_affine, operator==, affine_point::decode and its checks: variable time; public data only.
  • constexpr, noexcept, no allocation.
Errors

affine_point::decode returns std::nullopt for an encoding that is not SEC1 compressed or uncompressed, a coordinate at or above p, or a point not on the curve; to_affine returns std::nullopt for the identity.

Examples
namespace p384 = snicholls::crypto::p384;
const p384::point g = p384::point::base();
const p384::point two_g = p384::point::mul_base(p384::scalar::from_u64(2)); // constant time in the scalar
const bool same = two_g == g.dbl();
const p384::affine_point a = two_g.to_affine().value();
const auto back = p384::affine_point::decode(a.compressed()); // SEC1 (49 bytes), checked
auto bad = a.uncompressed();
bad[96] ^= 1;
const auto refused = p384::affine_point::decode(bad); // std::nullopt
Performance

mul: 384 doublings and 96 additions, each a complete addition (12 multiplications of six limbs). See BENCHMARKS.md.

Tests and demos

tests/p384/point_test.cpp: the generator on the curve, n G = identity, the group law, known multiples, and the SEC1 edge cases. demos/p384/point_demo.cpp.

Dependencies

<array>, <cstdint>; p384/field.hpp, p384/scalar.hpp, detail/weierstrass_a3.hpp.

Known issues and gotchas

The identity has no affine form and no SEC1 encoding: check to_affine before encoding.

Status

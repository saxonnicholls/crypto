Detailed Description

bip39::english: BIP-39's English word list, 2048 words, as a compile-time table.

Overview

The 2048 words a mnemonic is written in, sorted, each 3 to 8 lower-case ASCII letters, with the property BIP-39 relies on that the first four letters identify a word. english holds them as text; english_packed holds each as one 64-bit integer (the letters little-endian, zero-padded), so that a word can be looked up by comparing against every entry with masks (find_word_ct), in time that does not depend on the word.

Only the English list is included. BIP-39's other official lists are under the same licence, but French and Spanish carry accents and Japanese uses an ideographic space, so their mnemonics and seeds need NFKD normalisation, which this library does not have (see bip39/mnemonic.hpp); the rest would each add a table to every compile for little use. The generator takes another list the same way if one is wanted.

Implementations and variants

One table, generated.

Guarantees and contracts
  • constexpr data; find_word_ct is constexpr, noexcept, and scans all 2048 entries whatever the word.
  • The table is checked at compile time: sorted, unique, 3 to 8 letters, unique four-letter prefixes.
Errors

None: a word that is not in the list is index 2048 from find_word_ct.

Examples
namespace bip39 = snicholls::crypto::bip39;
static_assert(bip39::english[2047] == "zoo"); // the table is compile-time data
const auto i = bip39::find_word_ct(bip39::pack_word("legal")); // scans all 2048: constant time
const auto missing = bip39::find_word_ct(bip39::pack_word("bitcoin")); // not a BIP-39 word

Known issues and gotchas

The table is about 24 KB of text and 16 KB of packed words in every program that uses it.

Status

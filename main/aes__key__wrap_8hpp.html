Detailed Description

AES-256 key wrap (RFC 3394; JOSE's A256KW): a key encrypted and authenticated under a key-encryption key.

Overview

aes256_key_wrap(kek, key, out) wraps a key of n 64-bit blocks (n >= 2; 16, 24 or 32 bytes for AES keys) into n + 1 blocks; aes256_key_unwrap reverses it and checks the integrity value A6A6A6A6A6A6A6A6 in constant time, releasing nothing when it does not match. JWE's A256KW wraps the content-encryption key this way.

Relationships

detail/aes.hpp; aead/aes256_gcm.hpp. Group: Authenticated encryption.

Implementations and variants

One: RFC 3394 section 2.2.1 and 2.2.2 (the index-based form), six rounds over the blocks.

Guarantees and contracts

Constant time in the key-encryption key and the wrapped key; the length is public; the integrity check is a masked comparison whose result alone is revealed. Intermediates are wiped. constexpr, noexcept, no allocation.

Errors

errc::invalid_length for a key that is not a whole number of 64-bit blocks, fewer than two, more than 64, or an output of the wrong length; errc::authentication_failed from unwrap when the integrity value does not match.

Examples
namespace aead = snicholls::crypto::aead;
const auto kek = hex<32>("000102030405060708090a0b0c0d0e0f101112131415161718191a1b1c1d1e1f"); // RFC 3394's test KEK
const auto cek = hex_bytes("00112233445566778899aabbccddeeff000102030405060708090a0b0c0d0e0f"); // the key to protect
std::vector<std::uint8_t> wrapped(cek.size() + 8), unwrapped(cek.size());
const auto wrap = aead::aes256_key_wrap(kek, cek, wrapped);
const auto unwrap = aead::aes256_key_unwrap(kek, wrapped, unwrapped);
auto changed = wrapped;
changed[0] ^= 1;
const auto refused = aead::aes256_key_unwrap(kek, changed, unwrapped); // authentication_failed
Performance

6 n AES blocks.

Dependencies

<array>, <cstdint>, <span>; core's result.hpp.

Known issues and gotchas

Key wrap is for keys (uniformly random data), not messages: use an AEAD for anything else.

Detailed Description

secp256k1::point: the curve y^2 = x^3 + 7, complete addition, and constant-time scalar multiplication.

Overview

Points in homogeneous projective coordinates (X : Y : Z), with the complete addition and doubling formulas of Renes, Costello and Batina (2016, algorithms 7 and 9 for a = 0): one formula for every pair of inputs, the identity and equal points included, so the arithmetic has no special case to branch on. On top of it:

  • mul(k, p) and mul_base(k): k p in constant time, a 4-bit fixed window whose table entry is read by scanning all sixteen entries with masks (no secret index).
  • mul_add_public(a, b, q): a G + b q for verification and recovery, variable time (it only ever sees public values), Shamir's trick over two 4-bit windows.
  • affine_point, decompress, is_on_curve: the coordinates public keys are made of.
Relationships
  • secp256k1/field.hpp, secp256k1/scalar.hpp: the arithmetic underneath.
  • secp256k1/keys.hpp, secp256k1/ecdsa.hpp, secp256k1/schnorr.hpp: the users.

Implementations and variants

One. libsecp256k1 is faster (5 x 52 limbs, an endomorphism, precomputed comb tables for G, safegcd inversion); this is the short form whose every secret path is the same instruction sequence for every key.

Guarantees and contracts
  • Value types, trivially copyable, no allocation; every member constexpr and noexcept.
  • mul, mul_base, to_affine_ct, add, dbl: constant time in every argument.
  • mul_add_public, to_affine, decompress: variable time; they are only for public data.
Errors

None: the identity has no affine form (to_affine gives std::nullopt), a non-residue x has no point (decompress gives std::nullopt).

Examples
using namespace snicholls::crypto::secp256k1;
constexpr point two_g = point::base().dbl(); // the compiler doubles G
static_assert(two_g == point::base() + point::base()); // complete formulas: same answer
const point k_g = point::mul_base(scalar::from_u64(3)); // constant time in the scalar
const point check = point::mul_add_public(scalar::from_u64(1), scalar::from_u64(1), two_g); // public: G + 2G
const auto affine = k_g.to_affine(); // std::nullopt only for the identity
const auto from_x = decompress(generator().x, 0); // G from its x and parity
Performance

See benchmarks/secp256k1/ecdsa_benchmark.cpp (public key from private key is mul_base plus one inversion).

Tests and demos

tests/secp256k1/point_test.cpp (G, 2G and kG against published values, the group law at compile time, the identity in every position), demos/secp256k1/point_demo.cpp.

Dependencies

<array>, <cstdint>, <optional>.

Known issues and gotchas

Projective equality compares cross products; two different (X : Y : Z) can be the same point.

A point multiplication evaluated in a constant expression needs a raised step limit: see the gotchas of field.hpp.

Status

Experimental (0.1).

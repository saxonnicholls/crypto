Detailed Description

hd::derivation_path: BIP-32 paths ("m/44'/60'/0'/0/0"), strict parsing, formatting, and the BIP-44 family.

Overview

A derivation path is the list of child indices from a master key to a key; an index at or above 2^31 is hardened, written with a mark (', or h / H). This header holds a path in a fixed-capacity value, parses and formats its text, and builds the standard wallet paths:

Purpose Standard Use
44' BIP-44 the general multi-coin layout (Ethereum m/44'/60'/0'/0/i, TRON 195', Solana 501')
49' BIP-49 Bitcoin P2WPKH nested in P2SH
84' BIP-84 Bitcoin native SegWit P2WPKH
86' BIP-86 Bitcoin Taproot single key

all as m / purpose' / coin_type' / account' / change / address_index (wallet_path).

Strict grammar. "m", or "m" followed by components "/" index [mark], where the index is decimal with no sign, no leading zero (except "0" itself) and below 2^31, and the mark is ', h or H. Anything else (an empty component, a trailing slash, whitespace, "M", a hardened bit written as a number) is errc::invalid_path. A path is never silently changed: in particular nothing here hardens an index that was not marked.

Implementations and variants

One.

Guarantees and contracts
  • Paths are public data: this header is variable time and makes no constant-time claim.
  • Value type, trivially copyable, no allocation; every function constexpr and noexcept.
  • Capacity max_depth = 32 components. BIP-32 records depth in one byte (255), but no standard path is deeper than six, and a fixed capacity keeps the type small (132 bytes); a deeper path is errc::invalid_path.
Errors

errc::invalid_path for text that does not parse, an index at or above 2^31 given to a builder, a BIP-44 change other than 0 or 1, or a path deeper than max_depth.

Examples
constexpr auto eth = hd::bip44_path(hd::coin_type::ethereum, 0, 0, 0); // m/44'/60'/0'/0/0, at compile time
static_assert(eth && eth->size() == 5 && !eth->all_hardened());
const auto btc = hd::bip84_path(hd::coin_type::bitcoin, 0, 0, 0); // m/84'/0'/0'/0/0
const auto sol = hd::derivation_path::parse("m/44h/501h/0h/0h"); // h, H and ' all mark hardened
const auto bad = hd::derivation_path::parse("m/44'/060'"); // a leading zero: refused
std::array<char, hd::derivation_path::max_text_length> buf{};
const std::string eth_text(buf.data(), eth->format(buf));
const std::string btc_text(buf.data(), btc->format(buf));
const std::string sol_text(buf.data(), sol->format(buf)); // written back with '

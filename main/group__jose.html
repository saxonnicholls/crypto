Detailed Description

JWE's key agreement: ECDH-ES and ECDH-ES+A*KW on X25519 and P-256, with JOSE's Concat KDF (RFC 7518 4.6).

Template Parameters

Parameters

algorithmThe enc value for "alg": "ECDH-ES", else the alg value ("ECDH-ES+A256KW").
apuThe apu header value, base64url-decoded; empty when absent.
apvThe apv header value, base64url-decoded; empty when absent.

The key.

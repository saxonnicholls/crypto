Detailed Description

secp256k1::scalar: arithmetic modulo the group order n, constant-time and constexpr.

Overview

Private keys, nonces, signature components and hashes reduced into the group. Four 64-bit limbs, always below n = 2^256 - 0x14551231950B75FC4402DA1732FC9BEBF; every operation runs in time independent of the value.

Relationships
  • secp256k1/field.hpp: the same arithmetic modulo p.
  • secp256k1/ecdsa.hpp, secp256k1/schnorr.hpp: the users.
  • Group: secp256k1.
Implementations and variants

One: 4 x 64-bit limbs, the product folded four times by 2^256 = c (mod n), then one conditional subtraction.

Guarantees and contracts
  • Value type, trivially copyable, no allocation; every member constexpr and noexcept.
  • Constant time in the value, inverse included (Fermat with the public exponent n - 2).
  • from_bytes (strict) branches on whether the encoding is in range; use from_bytes_ct for a secret.
  • A scalar holding a secret is wiped by its owner (secp256k1::private_key does); the type itself does not wipe, so that it stays trivially copyable for the arithmetic.
Errors

None: an out-of-range encoding is std::nullopt or a zero validity mask.

Examples
using snicholls::crypto::secp256k1::scalar;
const auto n = scalar::order_bytes();
const bool order_rejected = !scalar::from_bytes(n); // a key must be below n
const auto reduced = scalar::from_bytes_reduced(n); // a hash is reduced: n -> 0
const auto s = -scalar::from_u64(1); // n - 1: a "high" s
const auto low = scalar::select(s.is_high_mask(), -s, s); // low-S normalisation, no branch
const bool inverse_ok = scalar::from_u64(3).inverse() * scalar::from_u64(3) == scalar::from_u64(1);
